# Activity Tracker

Activity Tracker is a Windows application that monitors which apps and windows are active on your computer, giving you a clear picture of how your screen time is spent throughout the day.

> **This repository is for releases only.** Source code is maintained in a separate repository.

## Current Version

**v1.4.0** — Private time.

## Download

Head to the [**Releases**](../../releases) tab to download the latest version.

| Asset                                    | Description              |
| ---------------------------------------- | ------------------------ |
| `Activity-Tracker-Installer-vx.x.x-.exe` | Windows 64-bit installer |

## Requirements

- Windows 10 or later (64-bit)

## Installation

1. Download the installer from the [latest release](../../releases/latest).
2. Run `Activity-Tracker-Installer-vx.x.x-.exe` and follow the prompts.
3. Launch Activity Tracker from the Start Menu or desktop shortcut.

## Updating

Download and run the installer for the new version — it will replace the previous installation automatically.
